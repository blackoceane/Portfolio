# Portfolio – Oceane Joyce Tiedjom Litchap

Mon site portfolio : qui je suis, mes projets, mes compétences et comment me joindre.

**Voir le site : https://blackoceane.github.io/Portfolio/**

## Technologies

HTML, CSS et JavaScript, sans framework ni bibliothèque. Le site est hébergé gratuitement avec GitHub Pages.

## Fonctionnalités

- **Mise en page adaptée** aux ordinateurs, aux tablettes et aux téléphones (CSS Grid, Flexbox, media queries)
- **Menu burger** sur téléphone, accessible au clavier et aux lecteurs d'écran (`aria-expanded`)
- **Filtre des projets** par domaine (logiciel, données, web, embarqué, jeu vidéo) en JavaScript
- **Formulaire de contact validé** : messages d'erreur sous chaque champ, puis ouverture de l'application de courriel avec le message déjà rempli (un site statique ne peut pas envoyer de courriel lui-même)
- **Accessibilité** : lien pour sauter au contenu, focus visible au clavier, animations réduites si l'utilisateur le demande
- **CV téléchargeable** en PDF

## Structure

- `index.html` : le contenu de la page
- `style.css` : les couleurs, les polices et la mise en page
- `script.js` : le menu burger, le filtre des projets et la validation du formulaire
- `cv-oceane-tiedjom-litchap.pdf` : mon CV
